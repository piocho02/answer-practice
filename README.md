# 나의 답안 연습실

서버와 DB 없이 브라우저에서 동작하는 정적 웹 앱입니다. 실행 소스는 `public/`에만 있습니다.

- 답안 작성기: `public/index.html`
- PDF → 답안 JSON 변환기: `public/pdf-to-json/`
- 작성기 글꼴: `public/assets/fonts/`

## 기능

문항별 기본 4쪽 및 자동 페이지 확장, 정렬·기호·확대·전체화면·타이머, PDF 인쇄, 브라우저 자동저장, JSON 내보내기·불러오기, 작성 내용 초기화를 지원합니다.

글자 서식은 왼쪽 툴바의 `서식` 툴박스에서 굵게·밑줄·형광펜을 지원합니다(굵게·밑줄은 Ctrl/⌘+B, Ctrl/⌘+U). 같은 툴박스의 일반 `가` 버튼은 선택한 범위의 서식을 모두 지웁니다(정렬은 유지). 서식은 답안 HTML 안에 `<b>`, `<u>`, `<span style="background-color: rgb(255, 245, 157);">` 세 가지 형태로만 저장되며 자동저장, JSON 내보내기·불러오기, PDF 인쇄에서 유지됩니다. 그 밖의 태그와 스타일은 불러올 때 제거됩니다.

집중 모드(툴바 하단 첫 버튼)를 켜면 키보드로 입력하거나 이동할 때 커서가 있는 줄이 화면 세로 중앙에 유지됩니다. 켜짐 여부는 브라우저에 기억됩니다.

상단 `작성 내용 초기화` 옆의 `타자 속도`에서 측정 방식을 고르면 그 옆에 분당 타수가 표시됩니다. 두벌식 기준으로 자모 하나를 1타로 세며 쌍자음은 1타, 겹모음·겹받침(ㅘ, ㄳ 등)은 2타입니다. 기호 버튼·붙여넣기·되돌리기로 들어간 글자와 줄바꿈은 세지 않습니다.

- 현재 속도: 최근 20초 동안 실제로 입력한 속도입니다. 3초 넘게 입력이 없으면 0으로 표시됩니다.
- 평균 속도: 측정을 켠 뒤의 평균입니다. 3초 넘게 멈춘 시간은 생각하는 시간으로 보고 뺍니다.
- 시험 시간 대비: 타이머가 흐르는 동안 입력한 타수를 지난 시험 시간으로 나눈 값입니다. 생각하는 시간을 포함한 실전 속도입니다.

측정값은 답안 JSON에 저장되지 않으며, 측정을 끄거나 작성 내용을 초기화하면 처음부터 다시 셉니다. `작성 내용 초기화`는 과목명도 기본값(연습문제)으로 되돌립니다.

답안은 사이트 주소별 브라우저 localStorage에 저장됩니다. 기기 간 이동은 JSON 내보내기·불러오기를 사용하세요. 답안 내보내기와 PDF 변환기의 JSON 다운로드는 지원 브라우저에서 파일명·저장 위치 선택 창을 엽니다. 미지원 브라우저는 기존 다운로드 설정을 따릅니다. 초기화는 모든 문항의 내용과 브라우저 저장 내용을 비우며 과목·문항 수·시간 설정은 유지합니다.

PDF 변환기는 텍스트 레이어가 있는 PDF(최대 30MB/200쪽)를 브라우저에서 처리합니다. PDF와 추출문은 서버에 업로드하지 않습니다. PDF.js 및 필요한 CMap·글꼴·WASM과 라이선스는 `public/pdf-to-json/vendor/`에 있습니다.

## 실행과 배포

설치·빌드·환경변수·DB가 필요하지 않습니다. Vercel은 `vercel.json`의 설정에 따라 `public/`만 정적 배포합니다.

로컬 실행: `python3 -m http.server 8000 --directory public`

변환기 검증: `node --test tests/converter.test.mjs`
