# 나의 답안 연습실

사례형 답안 작성 연습용 정적 웹 앱입니다. `index.html`을 브라우저에서 열거나 Vercel에 배포할 수 있습니다.

- 첫 쪽 30줄, 이후 34줄. 문항당 기본 4쪽에서 자동 확장
- 정렬, 기호, 확대·축소, 타이머
- 문항별 표와 페이지 테두리가 있는 PDF 인쇄
- 브라우저 자동 저장, 수동 저장 확인, JSON 내보내기와 불러오기

보관함 UI와 서버 API·DB 연결은 제거했습니다. 이 배포는 정적 파일만 제공하며 DB 환경변수를 사용하지 않습니다.

## 저장

답안은 현재 사이트 주소의 브라우저 localStorage에 저장됩니다. 저장 버튼은 파일 다운로드나 서버 업로드가 아닙니다. 기기·브라우저·사이트 주소가 달라지면 답안은 공유되지 않습니다. 다른 환경으로 이동하기 전 JSON 내보내기를 하고 새 환경에서 불러오세요. 브라우저 데이터 삭제 시 답안이 삭제될 수 있습니다.

## Vercel

이 저장소를 Import하고 Framework Preset을 Other로 선택합니다. 별도 설치와 빌드 명령은 필요하지 않습니다. 출력 디렉터리는 `public`입니다. 설정은 `vercel.json`에 포함되어 있습니다.

코드와 설정만 저장소에 포함하며 개인 답안은 포함하지 않습니다.

## PDF 답안 변환실

`/pdf-to-json/`는 텍스트 레이어가 있는 PDF를 답안 연습실 JSON(v1)으로 변환하는 독립 화면입니다. PDF 및 추출문은 서버로 전송하지 않습니다. PDF.js 6.4.299와 CMap, 표준 글꼴, WASM을 같은 사이트에서 제공합니다(라이선스: `pdf-to-json/vendor/LICENSE`).

- PDF 최대 30MB / 200쪽, 문항 최대 5개
- 원본 페이지 미리보기, 추출문 편집, 커서 기준 분리, 명시적 문항 제목 분리
- 페이지 범위 선택 및 선택적 줄바꿈·반복 머리말 정리
- 과목명과 현지 날짜를 사용한 JSON 다운로드(최대 5MB)
- 스캔 OCR, 표/다단 레이아웃의 완전한 복원, 서버 저장은 지원하지 않음
- 브라우저 새로고침 전 JSON을 내려받아야 편집 결과가 보존됨

검증: `node tests/converter.test.mjs`
